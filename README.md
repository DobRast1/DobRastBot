# 🌿 ДобРаст — ИИ-ассистент по уходу за растениями

🚀 **Умный бот в MAX** для тех, кто хочет растить растения без стресса и учиться на «отлично».

ДобРаст — это не просто напоминалка про полив, а полноценный ИИ-наставник для школьников и их учителей. Бот помогает вести дневник наблюдений за растениями, ставит диагнозы, напоминает о важных делах и генерирует готовые отчёты для сдачи проектов.

Разработан для Хакатона «Идея Фикс» (Сферум). 🏆

## ✨ Ключевые фишки

| Фишка | Описание |
|---|---|
| 🧠 Умный собеседник | Отвечает на вопросы по уходу с помощью GigaChat (Сбер). Не галлюцинирует — опирается на проверенные данные. |
| 📔 Интерактивный дневник | Сохраняет фото, записи и все действия. Работает синхронно с удобным веб-сайтом. |
| 🪪 Паспорт растения | Умный график полива, подкормки и опрыскивания, который подстраивается под каждое конкретное растение. |
| ⏰ Умные напоминания | Бот знает про «часы тишины» и никогда не разбудит ночью. |
| 📄 PDF-отчёт | Ученик одной кнопкой на сайте выгружает красивый бланк с наблюдениями для сдачи учителю. |
| 🤖 Распознавание текста | Понимает обычную речь: «полил лимон», «удали фикус», «поливай кактус раз в 2 недели». |

💡 Проект создан в образовательных целях в рамках Хакатона «Идея Фикс».

## 🚀 Установка и запуск

### 🐳 Вариант 1: Запуск через Docker (рекомендуемый для жюри)

Если вы хотите запустить всё в изолированном контейнере (это требуется по правилам хакатона):

1. Убедитесь, что у вас установлен Docker.

2. Соберите образ (находясь в папке проекта):

    docker build -t dobrost-bot .

3. Запустите контейнер (токены подтянутся из вашего `.env` файла):

    docker run --env-file .env -p 3000:3000 dobrost-bot

### 💻 Вариант 2: Локальный запуск

Если вы хотите запустить проект локально на компьютере:

1. Клонируйте репозиторий:

    git clone <ссылка_на_ваш_репозиторий>
    cd DobRastJS

2. Установите зависимости:

    npm install

3. Настройте переменные окружения — создайте в корне проекта файл `.env`:

    MAX_TOKEN=ваш_токен_от_бота_MAX
    GIGACHAT_AUTH_KEY=ваш_ключ_авторизации_GigaChat

4. Запустите бота:

    node index.js

5. Запустите веб-сервер (для дневника) — откройте второй терминал:

    node server.cjs

Сайт будет доступен по адресу `http://localhost:3000`

## 📁 Структура проекта

Для удобства жюри и проверяющих — вот из чего состоит проект:

| Файл | Назначение |
|---|---|
| `index.js` | Главный файл бота — логика общения, команды, интеграция с MAX API |
| `server.cjs` | Веб-сервер на Express для связи с сайтом-дневником |
| `index.html` | Интерфейс веб-дневника и генератор PDF-отчётов |
| `jarvis.cjs` | Модуль распознавания естественного языка (превращает фразы вроде «полил лимон» в команды) |
| `plants.cjs` | Управление списком растений и графиком |
| `diary.cjs` | Логика сохранения и чтения записей дневника |
| `reminders.cjs` | Система таймеров и напоминаний |
| `passport.cjs` | Логика составления паспорта растения |
| `plant_families.json` | База знаний о растениях (RAG) |
| `Dockerfile` | Файл для сборки контейнера |
