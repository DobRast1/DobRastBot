# 🌿 ДобРаст

**ИИ-наставник по растениеводству для платформы MAX.**

## 🚀 Как запустить
1. Установите зависимости: `npm install`
2. Создайте файл `.env` в корне проекта и добавьте свои ключи:
3. Запустите бота: `npm start`

## 🐳 Docker
```bash
docker build -t dobfast-bot .
docker run -d --env-file .env dobfast-bot
